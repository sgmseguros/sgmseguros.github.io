# SGM Seguros — Sitio web

Este paquete contiene la versión del sitio web preparada para subir a un repositorio.

## Estructura

- `index.html` — página principal del sitio.
- `robots.txt` — instrucciones para los motores de búsqueda.
- `sitemap.xml` — mapa XML del sitio para facilitar su indexación.
- `README.txt` — información básica del proyecto.

## Publicación

Los cuatro archivos deben quedar en la raíz pública del sitio, al mismo nivel que `index.html`.

## SEO

Si el dominio final del sitio no es `https://sgmseguros.uy/`, actualiza la URL indicada en `robots.txt` y `sitemap.xml` antes de publicar.

## Nota

Este README fue generado a partir del contenido disponible en el ZIP recibido. No se modificó el contenido de `index.html`.
